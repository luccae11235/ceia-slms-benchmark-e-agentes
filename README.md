# CEIA — SLMs, Benchmark e Agentes

Repositório de trabalho do grupo de benchmarks, treinamento e comportamento agêntico do projeto de Small Language Models do CEIA.

Durante a etapa de nivelamento, os materiais e artefatos serão organizados por semana de apresentação. A estrutura do repositório evoluirá conforme as necessidades das fases seguintes do projeto.
